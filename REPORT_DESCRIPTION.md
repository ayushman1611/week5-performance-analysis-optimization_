This Week 5 project presents a structured performance analysis and optimization strategy for a hypothetical Internal Communication Platform developed for a mid-sized company. The project follows the fifteen requirements shown in the internship task, including performance analysis, simulated data assessment, critical metrics, simulation methodology, benchmarking, theoretical modeling, user-load simulation, bottleneck identification, targeted optimization, trade-off analysis, report preparation, visual support, evaluation alignment, and demonstration of systems-analysis understanding.

Because production telemetry is not available for the academic scenario, the project clearly identifies its measurements as simulated data. The simulated workload evaluates the platform at 50, 100, 200, 400, 600, and 800 concurrent users. Key metrics include P95 response time, throughput, CPU utilization, memory utilization, database latency, and error rate. The results show increasing latency, database pressure, resource utilization, and errors at higher loads, while throughput begins to flatten. These trends are used to identify potential bottlenecks in database access, caching, connection management, application processing, and scalability.

The proposed optimization strategy includes database query and index optimization, Redis caching, connection-pool tuning, pagination, asynchronous processing, horizontal scaling, and improved monitoring. The report discusses the benefits, costs, complexity, risks, and validation approach for these changes. Charts, tables, a bottleneck architecture diagram, CSV datasets, and a Python analysis script are included so the project can be reviewed and reproduced. The Word report is designed as the main internship submission and explicitly maps to all fifteen task lines.
